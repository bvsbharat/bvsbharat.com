# Phase I MBBS Mentor–Mentee Logbook (CBME 2024)

Printable faculty logbook for **Gayatri Vidya Parishad Institute of Health Care and Medical Technology, Visakhapatnam**.

**1 mentor : 3 mentees**, monthly meetings, **12 sheets per mentee**.

## Files

- `Phase-I-Mentor-Mentee-Logbook.pdf` — print this
- `mentoring-logbook.html` — open in a browser to reprint
- `build_logbook.py` — regenerate the HTML if you change the layout

## How to print

1. Print **A4**, actual size (100%). Do not “fit to page” if you want writing space to stay aligned.
2. Single-sided is easier to write on; or duplex and keep in a **ring file**.
3. Use three colour flags / sticky tabs: **Mentee A / B / C**.

## Before first use

1. Cover already has the **GVPIHCMT emblem**, college name and Visakhapatnam address.
2. Faculty mentor is already printed: **Dr. Sushma Korukonda, MD, ACME**, Professor, Department of Anatomy. Fill academic year and batch.
3. During Foundation Course, complete each student’s **profile + SWOC** with them present.
4. Tick the **year-at-a-glance** table whenever a monthly meeting is done.

## What is inside

- Cover (logo box, institution, mentor)
- How to use + red-flag / privacy notes
- Year tracker for all three mentees + parent-meeting table (UGMEB/NMC may ask for parent records)
- For each mentee: profile, SWOC + quarterly AN/PY/BC snapshot, 12 one-page meeting sheets, year-end note
- Extra meeting page + confidential referral log (date and action only)

Each meeting sheet is tick-box heavy so a 15–20 minute meeting can be recorded before the student leaves.

Institution-specific names and logos are left blank so any college can use the same file.
